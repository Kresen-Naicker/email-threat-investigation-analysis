# Email Threat Investigation & Analysis

## Overview

This project simulates the workflow of a Security Operations Center (SOC) analyst investigating suspicious corporate emails. The investigation focuses on phishing detection, Business Email Compromise (BEC), IOC extraction, and risk classification.

## Skills Demonstrated

* Email header analysis (SPF, DKIM, DMARC, TLS)
* Sender and domain verification
* IOC extraction and documentation
* Phishing and social engineering analysis
* Risk classification
* Technical report writing

## Tools Used

* VirusTotal
* MXToolbox
* Email header analysis
* OSINT techniques

## Outcome

Produced a structured email threat investigation report containing evidence-based findings, IOC documentation, and remediation recommendations for a corporate environment.
